So what

Defensive takeaways

Blocklist these passwords

Deny-list the top 10 in your IdP; require manager-generated secrets.

Expect recon, not intrusion

Mostly uname/hostname/whoami in 2.29s sessions — alert on discovery bursts, not single logins.

Watch persistence paths

Writes toward authorized_keys keep recurring — alert on any unexpected one.

Method

How it works

Parsed Cowrie JSONL on sensor with Python json parser (same source Promtail ships to Loki). Raw IPs and file contents are not published; aggregates and command samples are shown.

Aggregates are published daily; the full dataset ships alongside as data.json.

One VM, one IP, one region — what hit this sensor, not the internet. Never attribution.
